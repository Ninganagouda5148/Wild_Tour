# Wild_Tour

Wild Tour is a full-stack travel and tourism web application designed to help users explore destinations, view tour packages, and plan their trips through an easy-to-use interface.

## 🚀 Features

- 🏠 Attractive home page
- 🌎 Explore popular tour destinations
- 🏕️ View tour packages and details
- 🔐 User registration and login
- 🎫 Tour booking functionality
- 👤 User profile management
- 📱 Responsive design
- 🛠️ Admin management features

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap

### Backend
- java
